# Evidence archive

Raw captures, packet dumps, descriptors, and model-specific analysis live here. Files are grouped by the hardware that produced them so X11 evidence is not accidentally generalized to X3/FA61, or vice versa.

- [`x11/`](x11/README.md) — X11 wired and 2.4 GHz adapter descriptors, captures, DPI samples, and macro samples.
- [`x3-fa61/`](x3-fa61/README.md) — X3/FA61 captures and exports.

Raw evidence must not be rewritten to match a theory. Interpretations belong in the protocol or research documents and must retain a link to the source artifact.
